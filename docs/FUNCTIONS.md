# 功能实现与成熟度

| 功能 | 如何实现 | 当前实际边界 |
| --- | --- | --- |
| 性格和聊天 | 角色卡 + 当前轮表达/意图提示 + 模型工具循环 | 有限真实/模拟排演，仍可能生硬或接错话；不是可保证的拟人评分 |
| 同人群聊/私聊接续 | QQ 身份 contracts/threads/recaps | 自动索引覆盖有限材料/话题；复杂观点仍需保存详细进展；保密范围仍有效 |
| 外号与梗 | 称呼约定优先，旧梗库为备用；自动用语带来源 | 三个面板统一；私聊生成内容不自动进入公开梗池；自动旧条目无来源时不跨场景使用 |
| 三类表情 | 文本 Emoji、OneBot face、收藏图片 ID | 工具可用并有表达提示，不保证每句话使用；收藏依赖账号自己的库 |
| 好感度 | 计数 × 权重 + 手动偏移，按初始值限幅 | 默认初始50/增量±45，因此最高95；普通每日10、正向每日3；长期不联系保留原缓慢回落规则 |
| 关系 | 消息量、相识时间、手动分层及低分覆盖 | 与好感是不同轴，高分不自动变死党；控制台解释而非制造等级提升 |
| 精力/作息 | 作息、聊天余力、后台任务资格和主动机会 | 夜猫子时段不等于永远有精力；活动倾向不代表任务已执行 |
| 追番 | 库/队列与每日自动模拟推进 | 计数是模拟，不下载或观看视频，不构成剧情知识 |
| 阅读/学习 | 实际网页片段、笔记、观点沿革、固定练习 | 有额度及失败/超时；合法试读或公开资料会变动；不代表读完整本小说 |
| B站内容 | URL/卡片解析、元数据及可用字幕 | Cookie/风控/字幕可用性影响成功；没有字幕时不等于看到了画面 |
| 主动联系 | 时间/精力/当前话题/未回应状态决定机会 | 有依据才可能发言，受额度/暂停/边界限制，不保证每个机会发出 |
| 好友与群目录 | 限定的只读 OneBot 查询 | 取决于登录和后端 API；不自动申请好友、给别人空间点赞 |
| 空间/资料 | 已接入的安全动作与公开内容草稿 | 部分写接口未完成现场验收，不应标为全部完善 |
| 语音 | 可选库及外部服务/媒体处理 | 默认关闭，voice-tool 独立工具未包含；配置后需要另行验收 |
| 启动与诊断 | 本机程序路径配置、端口/所有权检查 | 默认针对 Windows；不包含账号登录或第三方组件安装 |

好感度额度按原有 UTC 日期桶清零，在中国时区通常显示为次日08:00；页面显示实际重置时间。重复扫描聊天名单不会再次给历史好话加分。控制台能解释状态与结果，但不能由一个数值证明她“真的体验”了对应活动。
